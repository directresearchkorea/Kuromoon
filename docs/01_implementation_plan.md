# Kuromoon (쿠로문) — 구현 계획서

> **AI 검색 엔진(Gemini)이 한국 로컬 비즈니스 정보를 인용하여 트래픽을 유도하는, 초경량 자동화 디렉토리 웹사이트**

---

## 1. 프로젝트 개요

### 1-1. 핵심 가설
제미나이(Gemini), ChatGPT 등 생성형 AI 검색 엔진은 한국 로컬 정보(맛집, 뷰티, 팝업스토어 등)를 답변할 때 신뢰할 수 있는 출처(Source)가 부족하다. 네이버/카카오의 폐쇄형 플랫폼 장벽으로 인해 글로벌 AI 크롤러들은 한국의 고품질 로컬 데이터를 수집하기 어렵다.

**→ AI 크롤러가 가장 좋아하는 형태(정적 HTML + Schema.org JSON-LD)로 한국 로컬 정보를 구조화하여 웹에 공개하면, 제미나이가 이를 우선적으로 인용하고 출처 링크(URL)를 노출시켜 트래픽을 유도할 수 있다.**

### 1-2. 서비스 정의
- **서비스명**: Kuromoon (쿠로문)
- **슬로건**: "AI가 추천하는 한국 로컬의 진짜 평판"
- **도메인 후보**: `kuromoon.com` 또는 `kuromoon.com`
- **서비스 형태**: 초경량 정적(Static) HTML 디렉토리 웹사이트
- **로그인**: 없음 (제로 마찰 Zero-friction 구조)

### 1-3. 타겟 유저

| 세그먼트 | 언어 | 페르소나 |
| :--- | :--- | :--- |
| **한국 Z세대 (10~20대)** | 한국어 | 네이버 광고성 리뷰에 지쳐 구글/AI로 검증된 평판 정보를 찾는 트렌드 세터 |
| **한국 방문 외국인 관광객** | 영어 | 한국에 3~7일 체류하며 외국인 친화적인 뷰티/맛집/팝업 정보를 찾는 여행자 |
| **한국 거주 외국인(Expat)** | 영어 | 장기 거주하며 평판 검증된 로컬 서비스(병원, 미용실 등)를 찾는 거주자 |

## 2. 우선순위 카테고리 (MVP 범위)

> **[중요]** MVP는 **서울 주요 지역(성수, 홍대, 강남, 한남, 이태원)**에 한정하여 아래 4개 카테고리로 시작합니다.

### 2-1. 1순위: 팝업스토어 & 전시/이벤트
- **이유**: 1~2주 단위로 열리고 닫히는 특성상 정보가 인스타그램 피드에 흩어져 있어 검색이 매우 불편함. AI 검색 유입이 가장 폭발적으로 발생할 수 있는 카테고리.
- **주요 데이터 필드**: 이벤트명, 브랜드명, 기간(시작일~종료일), 주소, 운영시간, 입장료, 사전 예약 링크, 대표 이미지, 한 줄 요약
- **Schema.org 타입**: `Event`

### 2-2. 2순위: K-뷰티(미용실/헤어숍) & 외국인 친화 피부과/치과
- **이유**: K-뷰티 인기로 외국인 검색 수요가 폭발적이지만, 영어로 구조화된 정보가 거의 전무함. 단가가 높아 비즈니스 확장성이 우수.
- **주요 데이터 필드**: 상호명, 서비스 카테고리, 가격표, 예약 방법(카카오톡/인스타 DM), 외국인 소통 가능 여부, 최근 평판 요약
- **Schema.org 타입**: `BeautySalon`, `MedicalBusiness`

### 2-3. 3순위: 니치(Niche) 다이닝 (비건, 할랄, 혼밥)
- **이유**: 네이버/캐치테이블에서 특수 식성 필터링이 매우 어려움. AI 질문에 가장 빈번하게 등장하는 롱테일 키워드.
- **주요 데이터 필드**: 상호명, 식성 태그(비건/할랄/글루텐프리/혼밥), 대표 메뉴, 가격대, 예약 방법, 주차 여부
- **Schema.org 타입**: `Restaurant`

### 2-4. 4순위: 콘셉트/디저트 카페
- **이유**: "콘센트 많은 카페", "반려동물 가능 카페" 등 세부 속성 필터가 네이버에 없음.
- **주요 데이터 필드**: 상호명, 속성 태그(콘센트/와이파이 속도/반려동물/노키즈존), 대표 디저트, 가격대
- **Schema.org 타입**: `CafeOrCoffeeShop`

### 3-2. 기술 스택

| 레이어 | 기술 | 선정 이유 |
| :--- | :--- | :--- |
| **프론트엔드** | 바닐라 HTML + CSS + JS | AI 크롤러 100% 파싱 가능, 극한의 경량화 |
| **폰트** | Pretendard (한국어) + Inter (영어) | Google Fonts 기반 모던 타이포그래피 |
| **호스팅** | Vercel 또는 Cloudflare Pages | 정적 사이트 무제한 무료, 글로벌 CDN 자동 적용 |
| **자동화 런타임** | GitHub Actions (크론잡) | 월 2,000분 무료, 스케줄 기반 자동 실행 |
| **AI 데이터 정제** | Google Gemini 1.5 Flash API | 무료 등급 범위 내 작동, 한국어 이해도 우수 |
| **지도 검증** | 카카오 로컬 API | 일일 10만 회 무료, 한국 주소 정확도 최고 |
| **사업자 검증** | 공공데이터포털 국세청 API | 전면 무료, 실시간 영업 상태 확인 |
| **트렌드 감지** | 네이버 데이터랩 API | 일일 1,000회 무료, 연령대 필터 지원 |

### 3-3. 다국어 전략 (정적 URL 분리형)

자바스크립트 번역 라이브러리를 쓰지 않고, 언어별로 완전히 별개의 정적 HTML 파일을 생성합니다.

```
kuromoon.com/
├── ko/                          ← 한국어 전용 페이지
│   ├── index.html               ← 메인 (한국어)
│   └── places/
│       ├── gentlemonster-popup.html
│       └── cafe-oasis.html
├── en/                          ← 영어 전용 페이지
│   ├── index.html               ← Main (English)
│   └── places/
│       ├── gentlemonster-popup.html
│       └── cafe-oasis.html
├── robots.txt
├── sitemap.xml
└── llms.txt                     ← AI 크롤러 전용 사이트 요약 가이드
```

- **Hreflang 태그**: 각 페이지 `<head>`에 `<link rel="alternate" hreflang="ko">` / `<link rel="alternate" hreflang="en">` 삽입하여 구글이 유저 국적에 맞는 버전을 자동 매칭.
- **언어 전환**: 우측 상단 `KO | EN` 버튼 → 다른 언어의 정적 URL로 단순 링크 이동 (JS 1줄).

## 4. 자가 검증 파이프라인 (품질 관리 자동화)

사람의 검수 없이 시스템이 스스로 데이터를 검증하고, 신뢰도 점수(Confidence Score) 기반으로 자동 발행합니다.

### 4-1. 필터 1: 공인 API 생존 검증
- **국세청 사업자등록 상태조회 API**: 수집된 업체의 사업자 상태가 "영업중"인지 "휴업/폐업"인지 실시간 판별.
- **카카오/구글 지도 API Geocoding**: 텍스트 주소를 지도 좌표로 변환. 정상 좌표가 반환되지 않는 유령 주소는 자동 폐기.

### 4-2. 필터 2: 다중 소스 합의 알고리즘 (Consensus)
- 최소 3개 채널(네이버맵, 구글맵, 인스타그램 공식 계정)에서 정보를 교차 비교.
- 전화번호, 영업시간, 주소 등 핵심 데이터가 **2개 이상의 소스에서 동일**해야 신뢰도 점수 부여.
- 소스 간 정보 충돌 시 신뢰도 점수를 깎고 대기 상태로 분류.

### 4-3. 필터 3: 링크 활성화 테스트
- 수집된 예약/SNS URL에 HTTP 요청을 보내 `200 OK` 응답 여부를 확인.
- `404 Not Found`이거나 비정상 도메인이면 해당 링크만 제외하고 발행하거나 페이지 자체를 보류.

### 4-4. 최종 발행 기준

| 신뢰도 점수 | 조치 |
| :--- | :--- |
| **90점 이상** | ✅ 즉시 자동 발행 (빌드 & 배포) |
| **70 ~ 89점** | ⏸️ 발행 보류 → '검토 필요' 리스트 분류 |
| **70점 미만** | ❌ 스팸/오류 판정 → 영구 삭제 |

## 5. 유저 경험 (UX) 설계

### 5-1. 유저 유입 여정 (User Journey)

```
[1] 유저가 제미나이에 질문
    "이번 주 성수동 갈 만한 팝업 추천해줘"
         │
         ▼
[2] 제미나이가 구글 검색 → 쿠로문 데이터를 인용하여 답변 생성
    답변에 쿠로문 출처 링크 노출
         │
         ▼
[3] 유저가 출처 링크 클릭 → 쿠로문 웹사이트 유입
    (예약 버튼, 지도, 사진, 전체 리스트 확인)
         │
         ▼
[4] 쿠로문 내에서 추가 탐색 & 공유
    (카카오톡 공유, 인스타 DM 링크 복사, 찜하기)
```

### 5-2. 로그인 정책: 없음 (Zero-friction)
- 회원가입/로그인 기능 일체 불포함.
- 개인정보 수집 없음 → 개인정보 보호법 리스크 제로.

### 5-3. 공유 & 저장 기능 (로그인 대체)

| 기능 | 구현 방식 |
| :--- | :--- |
| **카카오톡 카드 공유** | 카카오 JavaScript SDK 연동. 버튼 클릭 시 장소 이미지+이름+주소가 담긴 카드형 메시지를 카톡으로 전송 |
| **인스타 DM용 링크 복사** | 클립보드 API로 숏링크 + 한 줄 소개 텍스트를 복사. "쿠로문 추천: [장소명] kuromoon.com/ko/..." |
| **찜하기 (하트)** | 브라우저 LocalStorage에 장소 ID를 저장. 로그인 없이 재방문 시에도 찜 목록 유지 |

### 5-4. 디자인 방향
- **테마**: 다크 모드 기본 + 라이트 모드 전환 지원
- **스타일**: 글래스모피즘(Glassmorphism), 부드러운 그래디언트, 미세 애니메이션
- **반응형**: 모바일 퍼스트 (유저의 90%가 스마트폰 접속)
- **SEO 강화**: Semantic HTML5 (`<header>`, `<main>`, `<article>`, `<footer>`), Open Graph 메타 태그

## 6. AI 크롤러 최적화 (GEO 전략)

### 6-1. Schema.org JSON-LD
모든 개별 업체/이벤트 페이지에 해당 비즈니스 타입의 JSON-LD 스키마를 `<head>` 내에 삽입합니다.

```json
{
  "@context": "https://schema.org",
  "@type": "Event",
  "name": "젠틀몬스터 성수 팝업",
  "startDate": "2026-07-07",
  "endDate": "2026-07-21",
  "location": {
    "@type": "Place",
    "name": "성수동 대림창고",
    "address": "서울특별시 성동구 성수이로 78"
  },
  "offers": {
    "@type": "Offer",
    "price": "0",
    "priceCurrency": "KRW",
    "availability": "https://schema.org/InStock"
  }
}
```

### 6-2. 크롤러 허용 정책

#### robots.txt
```
User-agent: *
Allow: /

User-agent: GPTBot
Allow: /

User-agent: Google-Extended
Allow: /

User-agent: PerplexityBot
Allow: /

Sitemap: https://kuromoon.com/sitemap.xml
```

#### llms.txt (AI 크롤러 전용 가이드)
사이트 루트에 `llms.txt` 파일을 배치하여 AI 모델에게 사이트의 구조와 핵심 콘텐츠를 마크다운 형태로 안내합니다.

### 6-3. Google Indexing API
새 페이지가 자동 배포될 때마다 Google Indexing API를 호출하여 구글봇에게 **"새 페이지가 생겼으니 즉시 수집해 달라"**는 요청을 자동으로 전송합니다.
