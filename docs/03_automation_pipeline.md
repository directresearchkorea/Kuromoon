# Kuromoon (쿠로문) — 자동화 파이프라인 기술 설계서

> **실시간 트렌드 감지 → 데이터 수집/AI 정제 → 자가 검증 → 자동 배포까지의 전체 자동화 시스템 상세 설계**
> 
> 작성일: 2026-07-07

---

## 1. 파이프라인 전체 흐름

```
[1단계: 트렌드 감지]
   - 네이버 데이터랩 API (10-20대 필터링)
   - 인스타그램 인기 해시태그 모니터링
       ▼ (급상승 키워드 추출: 예: '성수동 A 브랜드 팝업')

[2단계: 자동 수집 및 AI 가공]
   - 구글/네이버/인스타 검색 → 관련 업체/이벤트 상세 정보 수집
   - Gemini API가 수집한 글에서 주소, 시간, 예약 정보 등을 JSON 구조로 정제
       ▼ (구조화된 JSON 데이터 생성)

[3단계: 자가 검증 (3대 필터)]
   - 필터 1: 국세청 사업자 상태 API (영업중 여부)
   - 필터 2: 다중 소스 합의 알고리즘 (네이버맵 vs 구글맵 vs 인스타)
   - 필터 3: 링크 활성화 테스트 (HTTP 200 OK 검사)
       ▼ (신뢰도 90점 이상만 통과)

[4단계: 정적 페이지 생성 및 자동 배포]
   - 미리 짜둔 HTML 템플릿에 데이터를 주입하여 개별 HTML 파일 자동 생성
   - sitemap.xml 자동 갱신
   - GitHub → Vercel/Cloudflare Pages 자동 배포 (약 30초)
   - Google Indexing API로 즉시 색인 요청
```

## 2. 1단계: 트렌드 감지 엔진

### 2-1. 네이버 데이터랩 API

네이버가 공식 제공하는 무료 API로, 10대/20대 연령 필터를 걸어 특정 카테고리에서 급상승한 검색어를 실시간으로 추출합니다.

- **비용**: 무료 (0원)
- **일일 한도**: 1,000회
- **활용 방식**: 매시간 1회씩(하루 24회) 호출하여 1020세대의 급상승 키워드 추출
- **필터 옵션**: 연령대(10대, 20대), 카테고리(생활/문화, 식품, 패션/미용 등)

### 2-2. 인스타그램 해시태그 모니터링

- 성수동, 홍대, 강남 등 핵심 지역 해시태그의 최신 게시물을 모니터링
- 급상승하는 새로운 해시태그(예: `#성수팝업`, `#홍대신상카페`)를 감지하여 트렌드 키워드로 추출

### 2-3. 구글 트렌드 API

- 글로벌 검색 트렌드 보완용으로 활용
- 외국인 관광객이 한국 관련 영어 검색어에서 급상승하는 키워드 감지

## 3. 2단계: 데이터 수집 & AI 정제

### 3-1. 데이터 수집 소스

| 소스 | 수집 대상 | 방법 |
| :--- | :--- | :--- |
| 공공데이터 API | 사업자 기초 데이터 (상호명, 주소, 전화번호, 업종) | 소상공인시장진흥공단 상가정보 공공 API |
| 인스타그램 | 브랜드 공식 계정의 최신 게시물 (팝업 일정, 사진 등) | 공개 프로필 스크래핑 |
| 브랜드 공식 사이트 | 상세 정보 (운영시간, 예약 링크, 가격표 등) | 정적 페이지 스크래핑 |
| 구글 맵스 | 평점, 리뷰 수, 영업시간, 주소 | Places API |
| 네이버 지도 | 평점, 리뷰 수, 영업시간, 주소 | 웹 스크래핑 (소량) |

### 3-2. AI 정제 (Gemini API)

수집된 비정형 텍스트 데이터를 Gemini API에 전달하여 구조화된 JSON으로 변환합니다.

#### 프롬프트 설계 (예시)
```
아래 블로그 글 5개에서 해당 업체의 정보를 추출하여 다음 JSON 형식으로 응답해주세요.
누락된 정보는 null로 표시하세요.

{
  "name_ko": "상호명 (한국어)",
  "name_en": "Business Name (English)",
  "category": "카테고리",
  "address": "상세 주소",
  "phone": "전화번호",
  "hours": "영업시간",
  "price_range": "가격대",
  "reservation_url": "예약 링크 URL",
  "instagram": "인스타그램 계정",
  "tags": ["태그1", "태그2"],
  "summary_ko": "한 줄 요약 (한국어)",
  "summary_en": "One-line summary (English)",
  "foreign_friendly": true/false,
  "parking": true/false
}
```

#### 비용 예상
- Gemini 1.5 Flash: Google AI Studio 무료 등급에서 분당 15회 호출 가능
- 업체 1개당 약 2,000~4,000 토큰 소비 → 하루 50개 업체 처리 시 무료 범위 내

## 4. 3단계: 자가 검증 파이프라인 (3대 필터)

### 4-1. 필터 1: 공인 API 생존 검증

#### 국세청 사업자등록 상태조회 API
- **기능**: 사업자등록번호 또는 상호명+주소로 조회하여 "영업중", "휴업", "폐업" 상태 확인
- **비용**: 무료 (공공데이터포털)
- **판정 기준**:
  - "영업중" → 통과 (+30점)
  - "휴업" → 보류 (0점)
  - "폐업" → 즉시 폐기 (-100점)

#### 카카오 지도 API Geocoding
- **기능**: 텍스트 주소를 위도/경도 좌표로 변환
- **비용**: 무료 (일 10만 회)
- **판정 기준**:
  - 정상 좌표 반환 → 통과 (+20점)
  - 좌표 미반환 (유령 주소) → 즉시 폐기 (-100점)

### 4-2. 필터 2: 다중 소스 합의 알고리즘 (Consensus Algorithm)

최소 3개 채널에서 핵심 정보를 교차 비교합니다.

| 비교 항목 | 소스 A (구글맵) | 소스 B (네이버맵) | 소스 C (인스타그램) |
| :--- | :--- | :--- | :--- |
| 전화번호 | 02-1234-5678 | 02-1234-5678 | - |
| 영업시간 | 11:00~22:00 | 11:00~22:00 | "열한시부터 열시까지" |
| 주소 | 성동구 성수이로 78 | 성동구 성수이로 78 | "성수역 3번 출구" |

**합의율 계산**:
- 3개 소스 중 2개 이상 일치 → 신뢰도 +30점
- 2개 소스만 일치, 1개 충돌 → 신뢰도 +15점
- 소스 간 전면 충돌 → 신뢰도 0점, 대기 상태로 분류

### 4-3. 필터 3: 링크 활성화 자동 테스트

수집된 예약/SNS URL이 실제로 살아있는지 시스템이 직접 방문합니다.

- **HTTP Status Check**: 해당 URL로 가상 접속 요청 전송
- **판정 기준**:
  - `200 OK` → 통과 (+10점)
  - `404 Not Found` → 해당 링크만 삭제 후 발행 (+5점)
  - 도메인 자체 접속 불가 → 링크 제외 (+0점)
- **도메인 신뢰도 가산점**: `naver.com`, `catchtable.co.kr`, `instagram.com` 등 검증된 도메인이면 +5점 추가

### 4-4. 최종 신뢰도 점수 산정

| 검증 항목 | 최대 점수 |
| :--- | :--- |
| 국세청 사업자 상태 확인 | 30점 |
| 지도 좌표 검증 | 20점 |
| 다중 소스 합의 | 30점 |
| 링크 활성화 테스트 | 10점 |
| 도메인 신뢰도 가산점 | 10점 |
| **총점** | **100점** |

| 총점 범위 | 조치 |
| :--- | :--- |
| **90~100점** | ✅ 즉시 자동 발행 (빌드 & 배포) |
| **70~89점** | ⏸️ 발행 보류 → '검토 필요' 리스트 분류 |
| **0~69점** | ❌ 스팸/오류 판정 → 영구 삭제 |

## 5. 4단계: 정적 사이트 빌드 & 자동 배포

### 5-1. HTML 템플릿 기반 페이지 자동 생성

미리 디자인해 둔 HTML 템플릿에 검증 완료된 JSON 데이터를 주입하여 개별 정적 페이지를 자동 생성합니다.

```
[템플릿 파일]                    [JSON 데이터]
place-template.html    +    gentlemonster-popup.json
                       ↓
           places/gentlemonster-popup.html (완성된 정적 페이지)
```

### 5-2. sitemap.xml / llms.txt 자동 갱신

새 페이지가 추가될 때마다 `sitemap.xml`에 해당 URL을 자동으로 추가하고, `llms.txt`에도 새 콘텐츠 요약을 업데이트합니다.

### 5-3. GitHub Actions → Vercel 자동 배포

1. 생성된 HTML 파일을 GitHub 리포지토리에 자동 커밋(Commit) & 푸시(Push)
2. Vercel이 GitHub 변경 감지 → 자동 빌드 및 글로벌 CDN 배포 (약 30초 소요)
3. 배포 완료 후 Google Indexing API를 호출하여 즉시 색인 요청

### 5-4. 실행 스케줄

| 작업 | 주기 | GitHub Actions 크론 |
| :--- | :--- | :--- |
| 트렌드 키워드 감지 | 매시간 | `0 * * * *` |
| 신규 업체 데이터 수집 & AI 정제 | 하루 2회 (오전 6시, 오후 6시) | `0 6,18 * * *` |
| 자가 검증 & 자동 발행 | 하루 2회 (오전 7시, 오후 7시) | `0 7,19 * * *` |
| 기존 업체 정보 갱신 검증 | 주 1회 (일요일 새벽 3시) | `0 3 * * 0` |

## 6. 콘텐츠 결정 프로세스 요약

페이지에 들어갈 콘텐츠는 다음 3단계로 자동 결정됩니다.

### 6-1. 데이터 뼈대 정의 (카테고리별 필수 필드)

| 카테고리 | 필수 데이터 필드 |
| :--- | :--- |
| 팝업스토어/이벤트 | 이벤트명, 기간, 주소, 운영시간, 입장료, 사전 예약 링크, 대표 이미지, 한 줄 요약 |
| 미용실/병원 | 상호명, 서비스 카테고리, 가격표, 예약 방법, 외국인 소통 가능 여부, 평판 요약 |
| 식당 | 상호명, 식성 태그, 대표 메뉴, 가격대, 예약 방법, 주차 여부 |
| 카페 | 상호명, 속성 태그(콘센트/와이파이/반려동물), 대표 디저트, 가격대 |

### 6-2. AI가 비정형 데이터에서 알맹이 추출

여러 블로그/인스타 게시물에서 AI(Gemini)가:
1. **정보 추출**: 단서들을 모아 정확한 주소/운영시간 확정
2. **핵심 태그 추출**: 리뷰 감정 분석으로 장점 키워드 요약
3. **예약 링크 확보**: 공식 채널에서 예약 URL 추출

### 6-3. 3대 필터 자동 검증 후 발행 결정

- 90점 이상: 사람의 확인 없이 즉시 발행
- 70~89점: 보류 (수동 검토 대기)
- 70점 미만: 자동 삭제
